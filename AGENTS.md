# Разработка Superarmanda

Этот репозиторий — единственный канонический дом для разработки standalone skill
`superarmanda`. Изменения skill, его runtime и тестов делайте здесь через обычную
feature-ветку и pull request. Перед PR запускайте релевантные тесты и проверку
секретов; секреты, токены и ключи не хранятся в репозитории.

Политика fleet, admission allowlist и host-интеграции принадлежат конкретному
host, а не этому standalone skill. Если host/project требует такую интеграцию,
она обязательна и её нельзя копировать, менять или обходить из этого
репозитория. Unmanaged установка без требующей admission host-политики может
использовать обычный изолированный Git worktree.
